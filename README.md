# scoop-norc

[Scoop](https://scoop.sh) bucket for [norc-cli](https://norc.app/cli), the
headless cron job scheduler for norc.

## Install

```powershell
scoop bucket add norc https://github.com/norcapp/scoop-norc
scoop install norc/norc-cli
```

## Apps

- **norc-cli** — headless cron job scheduler; installs a per-user Scheduled
  Task that syncs this machine's crontab with the norc web vault.
